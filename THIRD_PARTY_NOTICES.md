- `.claude/skills/mermaid/references/`: copies of the [mermaid-js/mermaid](https://github.com/mermaid-js/mermaid)
  documentation, MIT licence; see [its LICENSE](https://github.com/mermaid-js/mermaid/blob/develop/LICENSE) for the copyright holders.
- `.claude/skills/frontend-slides/bold-template-pack/`: design templates from the same MIT repo;
  finished decks load fonts from Google Fonts or Fontshare when opened.

## Not included on purpose

- `waveform.py` and the audiogram template from kajisho5/ffmpeg-skill: the script can delete an existing
  file of the user's.
- frontend-slides `deploy.sh` (Vercel deploy) and `export-pdf.sh` (installs Playwright on every run).
- The threads-carousel Next.js renderer: it needs `bun install` and a dev server; only the planning
  skill is copied.
- Anthropic's docx, pptx, xlsx and pdf skills, including copies found inside other repos: their
  licence does not allow copying. They are available built in as `anthropic-skills:docx` and the others.
- Vendor publishing, image and analytics clients (Publora, Pixfaro, Apify, WoopSocial, DataForSEO),
  installers, MCP servers and promotional links: removed so every copied skill works without paid keys.
