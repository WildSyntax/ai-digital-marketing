# Open-source Claude / Agent Skills for marketing gaps not covered by coreyhaines31/marketingskills (as of 2026-11-05)

Method note: repo metadata (stars, licence, last commit) was pulled from the GitHub REST API on 2026-11-05 via `gh api`. For 12 repos (marked [LICENSE read]) I shallow-cloned and read the LICENSE file directly. For the others, the licence is GitHub's detection, which is based on the repo's LICENSE file (marked [GH-detected]). Red-flag checks were grep scans of the clones (curl|bash, API-key env vars, telemetry/PostHog strings, "ignore instructions" text). This is not a full code audit. Baseline: [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) has 58,491 stars, MIT, and was pushed 2026-11-04.

## Q1. Best candidates per gap: repo, owner, stars, last commit, licence, skill folders, what they do

### Takeaway
Two sources fill the platform gaps best: Sergey Bulaev's per-platform bundles (YouTube, X, Threads, Instagram, TikTok; all MIT, active) and the broad, eval-backed `social-media-skills/skills` (MIT). For analytics reporting, the best fits are AgriciDaniel/claude-seo `seo-google` (GSC/GA4) and Anthropic's `knowledge-work-plugins` marketing `performance-report` (Apache-2.0). Newsletters and podcasting are the weakest gaps. Nothing high-adoption and dedicated exists there; the best options are sub-skills inside broad MIT libraries (`ur-grue/autopunk-media-skills`, `social-media-skills/skills`).

## Q2. Dependencies: scripts, API keys, paid services, MCP servers

### Takeaway
Most writer-type skills (Bulaev writers, social-media-skills, rampstackco, autopunk, Jakeschincariol) run with no key. The "insights/analytics/data" skills almost all depend on a paid API, a hosted vendor MCP, or your own Google OAuth.

### Cited Findings
- **sergebulaev/* bundles:** they ship `lib/` Python clients (`apify_client.py`, `pixfaro_client.py`, `publora_client.py`, `approval.py`). Audience-insights skills read data "via Apify" (needs `APIFY_TOKEN`). Optional publishing goes through Publora (`PUBLORA_API_KEY`); optional images through Pixfaro (`PIXFARO_TOKEN`). The README says by default the skills "draft everything for you to paste into YouTube Studio." — [youtube-skills README](https://github.com/sergebulaev/youtube-skills); [x-skills README](https://github.com/sergebulaev/x-skills)
- **ScrapeCreators skills:** they need `SCRAPECREATORS_API_KEY` (30 references in the repo; ScrapeCreators is the vendor's own scraping API). — [repo](https://github.com/ScrapeCreators/social-media-research-skills)
- **AgriciDaniel `seo-google`:** your own Google OAuth/ADC credentials via `scripts/google_auth.py`, with tests for API-key safety and OAuth flow. Optional paid extensions (Ahrefs, DataForSEO, SE Ranking). — [repo](https://github.com/AgriciDaniel/claude-seo)
- **Anthropic marketing plugin:** its `.mcp.json` pre-wires HTTP MCP connectors (Slack, Canva, Figma, HubSpot, Amplitude, Notion, Ahrefs, Similarweb...). The Tribe AI brand-voice plugin uses Notion, Atlassian, Box, Microsoft 365 and Figma MCPs to discover brand materials. — [knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins/tree/main/marketing); [brand-voice](https://github.com/anthropics/knowledge-work-plugins/tree/main/partner-built/brand-voice)
- **Ryze:** it requires the hosted Ryze MCP (`https://connector.get-ryze.ai/mcp`, Google sign-in connecting GSC, GA4 and ads), "with DataForSEO built in". — [README](https://github.com/Ryze-AI-Adgent/open-seo-mcp-skills)
- **Dataslayer:** it uses the Dataslayer MCP (a paid data connector for 50+ platforms) "or paste your own CSV/JSON manually". The full plugin requires a Claude Cowork plan; individual zips work on any plan. — [README](https://github.com/Dataslayer-AI/Marketing-skills)
- **seranking/seo-skills:** it requires `SERANKING_API_KEY` (a paid SE Ranking account). — [repo](https://github.com/seranking/seo-skills)
- **clamp-sh:** no keys. It assumes an analytics MCP (GA4, Mixpanel, PostHog, etc.) via `tool-maps/`. — [README](https://github.com/clamp-sh/analytics-skills)
- **alirezarezvani `youtube-full`:** `pip install yt-dlp youtube-transcript-api`, no API key. The skill tells the agent "do not install packages into their environment without asking." — [SKILL.md](https://github.com/alirezarezvani/claude-skills/blob/main/marketing-skill/skills/youtube-full/SKILL.md)
- **Substack `substack-publisher`:** it authenticates with a Substack session cookie (`substack.sid`). — [repo](https://github.com/Arin117Kaushik/substack-skills)
- **social-media-skills/skills:** mostly prompt-only. Scattered references to `ELEVENLABS_API_KEY` (voiceover) and a `TRAFFIC_TOKEN`. Install is `npx skills add social-media-skills/skills`. — [repo](https://github.com/social-media-skills/skills)

### Inferences
- If you want key-free installs, take only the writer/planner skills from the Bulaev bundles and leave out `*-audience-insights` and publishing.

### Gaps
- I did not verify Apify, Publora, Pixfaro, ScrapeCreators or Dataslayer pricing pages. The "paid" characterisation of Apify and ScrapeCreators rests on their being commercial APIs, not on a fetched price list.

## Q4. Red flags

### Takeaway
I found no prompt-injection text or exfiltration in the 12 scanned clones. The flags are vendor funnels (UTM-tagged sign-up links, hosted MCPs that see your GSC/GA4/ads data), one curl|bash install option, cookie-based auth, and suspicious star patterns around Jakeschincariol/youtube-agent-skill.

### Cited Findings
- **seranking/seo-skills** offers a `curl -fsSL https://raw.githubusercontent.com/seranking/seo-skills/main/install.sh | bash` one-liner. The script says it is "designed to be safe under curl ... | bash". A git clone alternative exists. The "telemetry/PostHog" grep hits were example content, not tracking code. — [README](https://github.com/seranking/seo-skills)
- **Ryze:** the README funnels users to a hosted MCP with UTM links ("Connect Ryze in one click"), so your Search Console, GA4 and ads data flows through a third-party vendor. Its `install.sh` only copies skill folders into `~/.claude/skills`. — [README](https://github.com/Ryze-AI-Adgent/open-seo-mcp-skills)
- **sergebulaev bundles:** the READMEs promote Publora and Pixfaro with UTM-tagged sign-up links. Publishing is approval-gated ("Nothing gets posted without your approval"). — [x-skills README](https://github.com/sergebulaev/x-skills)
- **Substack `substack-publisher`:** it handles the `substack.sid` session cookie, which is a full-account credential. Treat it as sensitive. — [repo](https://github.com/Arin117Kaushik/substack-skills)
- **Jakeschincariol/youtube-agent-skill:** it has 4,540 stars, while the same author's `x-agent-skill` has 71. Several **empty** repos named after it each carry stars: `whitetube-maker/Repo` (15 stars, description "Install this skill, then..."), `nk711457-spec/https-github.com-Jakeschincariol-youtube-agent-skill` (13), `gamesishant-maker/Yt-skill`, and `sahanvajsiddiqui2006/...`. The GitHub API returned "Git Repository is empty" for all four, created Sept–Oct 2026. This pattern suggests star or SEO manipulation, or a lure campaign. The original repo's code looked benign in my scan (MIT, small local Python scripts, no network calls found). — [GitHub search](https://github.com/search?q=youtube-agent-skill&type=repositories); [original](https://github.com/Jakeschincariol/youtube-agent-skill)
- **Ecosystem context:** Snyk's ToxicSkills scan of 3,984 ClawHub/skills.sh skills found 76 confirmed malicious payloads, with 13.4% having at least one critical issue. — [Snyk](https://snyk.io/pt-BR/blog/toxicskills-malicious-ai-agent-skills-clawhub); a large-scale arXiv analysis of 238,180 skills argues that scanners over-flag — [arXiv 2603.16572](https://arxiv.org/html/2603.16572v1)
- **fatihaydost** README: "No telemetry; nothing is uploaded." — [repo](https://github.com/fatihaydost/brand-identity-skill)

### Inferences
- Copy files from upstream git directly, not via `npx skills add -y` or curl|bash. Never install from look-alike repo names.
