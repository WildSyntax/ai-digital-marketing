# Examples

These files are dry-run outputs for the placeholder Northwind brand. They show what each
skill produces: ideas, blog, LinkedIn, Instagram and YouTube drafts, an SEO report, and a
weekly review. Folder structure mirrors the live workspace (`content/...`, `reports/...`).

- They are not in the live queue. Skills, the weekly review, and topic-ideas dedupe only
  look under `content/` and `reports/`, never here.
- The `published_url` in the example blog is a local path from a dry run. Nothing went live.
- Delete this folder once you have your own content.
